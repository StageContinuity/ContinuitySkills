# Review checklist template

Ask which project and review scope this should apply to. Tailor this draft with the user before applying it:

- Inspect the changed behavior and identify concrete regressions.
- Run relevant checks and report what was not verified.
- Keep findings tied to file locations and reproducible evidence.
- Save a review report with provenance and a one-line summary.

Creating this draft does not authorize posting reviews or changing repository policies.
